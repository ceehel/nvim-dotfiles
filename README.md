# Personal NeoVim config files

## Introduction

This is my personal take on LazyVim. I really like the approach overall but
some points do not suit my taste. I does bring a lot in a neatly packaged
format, though. This is a work in progress and is here for both personal use
as well as documenting the journey. Should it help anybody, the repository is
made public.

## Main adjustments

- Theme is matte black [GitHub](https://github.com/tahayvr/matte-black-theme)
- Line numbers are relative
- The line where the cursor is is highlighted

## Future adjustments

- Removing some pop menus that I find distracting
- The autocorrect or suggestion system is a bit obnoxious so find a way to tame
  it
- The line numbers column gets offset depending on the number of digits. It is
  a small thing but it kind of bothers me
